# Beli Reminders

Beli sends these reminders automatically 4 days before the end of each month.
To add a new reminder, just add a new block below following the same format.
To disable one, delete it or comment it out with a `#`.

---

## X.com Developer Subscription
- **Action:** Check whether I need to buy more API limit/capacity
- **Reason:** Confirm whether I need to renew or increase the credit before the billing cycle ends

## Firecrawl
- **Action:** Check whether I should renew or upgrade Firecrawl
- **Reason:** Confirm whether the scraping/extraction service is still needed

## Brave Search
- **Action:** Review the Brave Search service (activated May 12, 2026)
- **Reason:** Confirm whether it is still useful or whether switching to another option makes more sense

## Claude Console (Anthropic API)
- **Action:** Check usage and billing for the Anthropic API
- **Reason:** Confirm the service that powers the Beli Telegram bot is within budget and performing well
