# Beli Reminders

Beli sends these reminders automatically 4 days before the end of each month.
To add a new reminder, just add a new block below following the same format.
To disable one, delete it or comment it out with a `#`.

---

## Example: Monthly Subscription
- **Action:** Check whether I need to renew or adjust this subscription
- **Reason:** Confirm the service is still useful before the billing cycle ends

## Example: API Credit Check
- **Action:** Review usage and billing for this API
- **Reason:** Make sure the service is within budget and performing well
